3. A 3×3 "grid" using only divs and spans (zero CSS)

No <table>, no stylesheet, no style attribute. A <div> is block-level so it just stacks into a new row on its own. A <span> is inline so it sits next to whatever's beside it. That's the whole trick. Box-drawing characters and non-breaking spaces do the rest:

| R1C1 | | R1C2 | | R1C3 |
| R2C1 | | R2C2 | | R2C3 |
| R3C1 | | R3C2 | | R3C3 |

Three row <div>s, each forcing a new line. Each row holds three separate <span>s, one per cell, joined by &nbsp; so they don't wrap. Nine cells, nine spans, no CSS layout anywhere on this one.

5. Same text, 6 font sizes, inline styles

  • The quick brown fox jumps over the lazy dog. 12px, absolute. This is what fine print and copyright lines are made of, small on purpose and locked to a pixel value rather than scaling with a parent's font-size.
  • The quick brown fox jumps over the lazy dog. 22pt, absolute. Points are a print unit that scales with dpi settings, so this matters most once a page is headed for paper instead of a screen, something like a PDF invoice.
  • The quick brown fox jumps over the lazy dog. 1.5em, relative to the parent. Put this inside a button or card component and it'll scale with whatever font-size that component ends up with.
  • The quick brown fox jumps over the lazy dog. 1.75rem, relative to the root element. My default for headings, since it doesn't matter how many divs deep it's buried, it always answers to the same base size.
  • The quick brown fox jumps over the lazy dog. 120%, relative to the parent. A bit bigger than the paragraph around it, nothing dramatic, think pull-quote and not billboard.
  • The quick brown fox jumps over the lazy dog. 4vw, tied to the browser's width. Resize the window and the text actually shrinks or grows with it, which is why hero headlines love this one.

6. Positioning options, live

The navbar up top is already position: sticky. Here are three more in one little demo box, plus a bonus fixed pill hanging out in the corner of the browser window:

static box (default flow)
relative box (nudged 14px down, 30px right from where it would sit)

PositionWhen I'd actually use it
stickyNavbars, mostly. Scrolls with the page like normal, then locks to the top once it hits the edge.
staticThis is the default for everything. Position only becomes a thing worth thinking about once static stops being enough.
relativeEither a small nudge off its normal spot, or (more often, honestly) just to give an absolutely positioned child something to anchor to.
absolutePinning something to a corner of its container, like a little "sale" tag stuck on a product card.
fixedStuff that should never move no matter how far the page scrolls: a chat bubble, a cookie banner. That teal pill bottom-left is doing exactly this.
